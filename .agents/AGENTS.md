# Правила работы с проектом "Portfolio Ekaterina"

Этот файл автоматически читается агентами при старте сессии.

## Контекст Проекта
- **Владелец:** Екатерина Разумова (Creative Generalist).
- **Суть проекта:** Двойное портфолио. Шапка делит сайт на два мира: Профессиональная сторона (лендинг специалиста полного цикла: тексты, PR, UX/UI) и Творческая сторона (Mixed Art).
- **Визуальный стиль:** Тёмная тема (`#111111`), шрифты `Montserrat` и `Inter`, бирюзовый акцент (`#14F1D9`), элементы glassmorphism, абстрактные мазки краски, текстура мятой белой бумаги.

## Документация (ОБЯЗАТЕЛЬНО К ПРОЧТЕНИЮ)
Перед любыми архитектурными правками или добавлением новых блоков, агент **обязан** прочитать:
1. `docs/structure.md` — глобальная архитектура сайта.
2. `docs/decisions.md` — лог важных решений.
3. `docs/blocks/*.md` — документацию по конкретному блоку, который нужно изменить.

Никакой самодеятельности. Всегда сверяйся с этими файлами перед тем, как писать код.
