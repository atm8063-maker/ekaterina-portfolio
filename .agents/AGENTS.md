## СТАРТОВЫЙ ПРОТОКОЛ (выполнить ДО любой работы)

### Шаг 1: Загрузи контекст
1. Прочитай `docs/STATE.md` — текущее состояние проекта, карта блоков, известные баги
2. Прочитай `docs/DESIGN_SYSTEM.md` — цвета, шрифты, компоненты
3. Прочитай `docs/BACKLOG.md` — список тикетов

### Шаг 2: Определи тикет
1. Найди в BACKLOG.md тикет, соответствующий запросу пользователя
2. Если тикета нет — создай новый и ПОКАЖИ пользователю перед началом работы
3. Отметь тикет как 🔵 IN PROGRESS

### Шаг 3: Уточняющие вопросы
**ОБЯЗАТЕЛЬНО задай минимум 1 уточняющий вопрос перед началом работы.**
Примеры:
- «Ты имеешь в виду удалить совсем или закомментить?»
- «Это должно повлиять на блок X или только на Y?»
- «Я правильно понял — трогаем ТОЛЬКО этот файл, остальные не трогаем?»

**НЕ НАЧИНАЙ работу пока не получишь подтверждение.**

### Шаг 4: Снепшот
1. Перед началом работы: `git add -A && git commit -m "snapshot: before TICKET-XX — описание"`
2. После завершения: `git add -A && git commit -m "feat(TICKET-XX): описание"`

## ЖЕЛЕЗНЫЕ ПРАВИЛА

### 1. Изоляция проекта
- ❌ ЗАПРЕЩЕНО использовать код, стили или решения из `portfolio-website` или любого другого проекта
- ❌ ЗАПРЕЩЕНО импортировать компоненты из других проектов
- ✅ Работаем ТОЛЬКО в папке `portfolio Ekaterina`

### 2. Не ломай готовые блоки
- Перед изменением ЛЮБОГО файла проверь в `docs/STATE.md`, какой у блока статус
- Если статус ✅ Готов — **НЕ ТРОГАЙ** без явного запроса пользователя
- Если нужно что-то изменить в готовом блоке — СПРОСИ СНАЧАЛА

### 3. Блоковый подход
- Работаем по одному блоку за раз
- Не переходим к следующему, пока текущий не закончен и не согласован
- Каждый блок = набор тикетов в BACKLOG.md

### 4. Обновляй документацию
- В конце каждой сессии обнови `docs/STATE.md`
- При изменении стилей обнови `docs/DESIGN_SYSTEM.md`
- При завершении тикета обнови его статус в `docs/BACKLOG.md`

### 5. Коммуникация
- Не додумывай за пользователя. Если есть сомнения — спроси
- Если пользователь говорит «всё на месте» — уточни, это «ок» или «проблема на месте»
- Не делай ничего, о чём не просили
