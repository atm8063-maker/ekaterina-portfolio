# Концепции Логотипа: NP Consulting (NPC)

Логотип бренда — это не просто картинка, а динамический консольный элемент, отражающий процесс "написания кода" или "ввода команды". Он должен идеально смотреться как на сайте, так и на аватарках в соцсетях.

Все варианты ниже используют моноширинный шрифт программистов **`JetBrains Mono`**. 

---

## 🎨 Фирменные цвета логотипа

Логотип адаптируется под тему (Тёмную или Светлую):

*   **Тёмная тема (Dark Mode):** 
    *   Фон: Глубокий чёрный (`#050505`)
    *   Цвет текста: Белый (`#ffffff`)
    *   Цвет курсора: Неоновый мятный (`#00FFA3`) с легким свечением.
*   **Светлая тема (Light Mode):**
    *   Фон: Светло-серый (`#f8f9fa`)
    *   Цвет текста: Тёмно-серый (`#111827`)
    *   Цвет курсора: Изумрудный (`#00A669`).

## ⬛️ Концепты Логотипа

Во всех концептах используется анимация мигания прямоугольного терминального курсора `▮`.

### Концепт 1: "Ожидание ввода" (Минимализм)
Классический пустой массив (или скобки) и ожидающий курсор снаружи. Отлично смотрится в шапке сайта, когда нужно сэкономить место.
```text
[ ] ▮
```
*Анимация:* Прямоугольник `▮` плавно мигает (исчезает и появляется раз в секунду).

### Концепт 2: "В процессе" (Аватарка)
Курсор находится внутри скобок. Это символизирует, что процесс запущен, код пишется, задача решается прямо сейчас.
```text
[ ▮ ]
```
*Идеальное применение:* Это лучший вариант для квадратных и круглых форматов (например, для аватарки в Telegram, LinkedIn, Threads). 

### Концепт 3: "Динамика" (Основной для сайта)
Самый сложный и эффектный вариант. Логотип меняется при наведении или работает циклично при загрузке.
```text
Состояние 1:  [   ] ▮
Состояние 2:  [ N ] ▮
Состояние 3:  [ N P ] ▮
Состояние 4:  [ N P C ] ▮
```
*Анимация:* Внутри скобок по одной букве "печатается" аббревиатура **NPC**, после чего курсор продолжает мигать. Именно этот вариант мы используем в главном меню на сайте.

## 💻 CSS-код для анимации курсора

Для реализации мигания курсора (как в консоли разработчика) используется простая CSS анимация:

```css
@keyframes blink {
  0%, 100% { opacity: 1; }
  50% { opacity: 0; }
}

.logo-cursor {
  /* Цвет зависит от темы (Light/Dark) */
  color: #00FFA3; 
  animation: blink 1s step-end infinite;
  display: inline-block;
}
```
