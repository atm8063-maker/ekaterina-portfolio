# Media Kit: NP Consulting (NPC)

Этот документ описывает строгий визуальный стиль сайта **NP Consulting**. Главная цель дизайна — создать чистый, функциональный и технологичный интерфейс (AI-native) без излишнего визуального шума.

Стиль поддерживает две равнозначные темы: Светлую (Light) и Тёмную (Dark).

---

## 🎨 1. Цветовая палитра (UI Colors)

Все цвета заданы строго в HEX-формате. Не используйте промежуточные или "грязные" оттенки серого.

### Светлая тема (Light Mode)
Базовая тема для корпоративного и строгого представления.
*   **Background:** `#f8f9fa` (Светло-серый, не чистый белый)
*   **Text Primary:** `#111827` (Тёмно-серый, для заголовков)
*   **Text Secondary:** `#374151` (Мягкий серый, для абзацев)
*   **Text Muted:** `#6b7280` (Для подписей и тегов)
*   **Accent Mint:** `#00A669` (Тёмно-изумрудный, для кнопок и ссылок)
*   **Grid Line:** `rgba(0, 0, 0, 0.06)` (Цвет линий фоновой сетки)

### Тёмная тема (Dark Mode)
Тема для фокусной работы, отсылает к интерфейсам IDE (редакторов кода).
*   **Background:** `#050505` (Глубокий чёрный)
*   **Card Background:** `#111111` (Подложки карточек и меню)
*   **Text Primary:** `#ffffff` (Чистый белый)
*   **Text Secondary:** `#e4e4e7` (Светло-серый / Zinc 200)
*   **Text Muted:** `#a1a1aa` (Приглушённый текст)
*   **Accent Mint:** `#00FFA3` (Неоновый мятный, Electric Mint)
*   **Grid Line:** `rgba(255, 255, 255, 0.16)` (Цвет линий фоновой сетки)

## 🔠 2. Типографика (Google Fonts)

Мы используем три шрифта для создания баланса между техничностью и читаемостью.

1.  **Space Grotesk** — Заголовки (Headings, Кнопки, Цифры)
    *   *Начертание:* Bold (700).
    *   Геометричный гротеск, задающий строгий, но современный тон.
2.  **Manrope** — Основной текст (Body)
    *   *Начертание:* Regular (400) / Medium (500).
    *   Чистый, максимально читаемый шрифт для абзацев и описаний кейсов.
3.  **JetBrains Mono** — Технические элементы (Логотип, Код)
    *   *Начертание:* Regular (400) / Bold (700) для логотипа.
    *   Используется только для смысловых технических вставок.

## ⚡ 3. Ключевые элементы (Signature Elements)

### Логотип (Анимация консоли)
Аббревиатура NPC, оформленная как ввод команды в терминал:
```text
[ NPC ] ▮
```
*Правила анимации:*
Символы появляются по очереди: `N` → `P` → `C`. 
В конце строки всегда находится прямоугольный курсор (`▮`), который плавно мигает с периодом в 1 секунду.

### Строка-статус (Hero Section)
Вместо классических бейджей используется строка терминала шрифтом JetBrains Mono:
```text
[ Открыта к проектам ] ▮
```
Курсор также мигает (цвет: Accent Mint).

### Инженерная сетка (Tech Grid)
Сетка — обязательный элемент фона главного экрана.
*   **Размер ячейки:** `40px` на `40px`.
*   Сетка не должна перебивать контент. Используйте заданные цвета (`0.06` прозрачности для светлой темы и `0.16` для тёмной).

**CSS-код для сетки:**
```css
.bg-grid-pattern {
  background-size: 40px 40px;
  background-image: 
    linear-gradient(to right, var(--grid-line) 1px, transparent 1px),
    linear-gradient(to bottom, var(--grid-line) 1px, transparent 1px);
}
```

## 📦 4. Правила UI (Формы и Элементы)

*   **Углы (Border Radius):** Строго `4px`. Запрещены сильно скруглённые (круглые) кнопки. Только строгие, слегка смягчённые углы.
*   **Кнопки:** 
    *   Заглавные буквы (UPPERCASE).
    *   Шрифт: Space Grotesk.
    *   Цвет фона: Accent Mint.
*   **Hover-эффекты:** Мягкое неоновое свечение при наведении на акцентные кнопки в тёмной теме (`box-shadow: 0 0 20px rgba(0, 255, 163, 0.4)`). В светлой теме свечение менее интенсивное (`0.3` прозрачности).
