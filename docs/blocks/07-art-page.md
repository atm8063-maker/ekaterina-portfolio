# Блок 07: Страница Творчества (Mixed Art)

## Назначение
Вторая смысловая "вселенная" проекта. Место для самовыражения, где профессиональные кейсы уступают место искусству. 

## Навигация
Доступ к странице осуществляется через главное меню в шапке (переключатель Professional -> Art).

## Структура (Черновик для обсуждения)
1. **Art Hero**
   - Визуально взрывная секция. Ещё больше абстракций, красок или 3D/Mixed Art элементов.
   - Заголовок: Что-то эмоциональное, отражающее творческое кредо.
2. **Галерея Работ (Gallery)**
   - Masonry-сетка (плитка) с творческими работами, картинами, инсталляциями.
   - При клике на работу — полноэкранный Lightbox с деталями текстуры и описанием смысла работы.
3. **Манифест (Manifesto)**
   - Текст о подходе к искусству и вдохновении.
