<section class="section" id="context">
  <span class="section-number">01 / Контекст</span>
  <h2 class="section-h2">Сколько стоит <em>адаптация контента</em></h2>

  <p class="lead">Рынок недвижимости глобален. Нельзя просто выложить объект на русском и ждать миллионных сделок. Нужны версии на английском, немецком, локальном (например, черногорском) языках. Плюс, текст для сайта не подходит для Instagram — там нужны эмодзи и хештеги. А текст для Instagram не подходит для агрегаторов.</p>

  <p>Обычно агентства нанимают штат копирайтеров и переводчиков, которые берут исходник и сутками переписывают его под разные форматы. Это дорого, медленно, а в переводах теряется "продающая" стилистика.</p>

<section class="section" id="killer-feature">
  <span class="section-number">02 / Магия под капотом</span>
  <h2 class="section-h2">Один исходник превращается в <em>13 форматов</em></h2>

  <p>Мы выделили эту задачу в отдельный модуль — Бот-Конвейер (Translator). Бот забирает сырой черновик (или голосовое от агента) и прогоняет его через мощные промпты Gemini. На выходе получается готовая матрица контента для дистрибуции:</p>

  <ul class="schedule-list">
    <li>
      <span class="when">6 версий</span>
      <span class="what"><strong>Для мультиязычного сайта.</strong> Локализованные SEO-описания на 6 языках. Gemini понимает контекст недвижимости и правильно переводит термины (студия, пентхаус, видовая).</span>
    </li>
    <li>
      <span class="when">3 версии</span>
      <span class="what"><strong>Для соцсетей.</strong> Уникальные посты с правильной стилистикой для Instagram (эмодзи, хештеги), Facebook и родного Telegram-канала.</span>
    </li>
    <li>
      <span class="when">1 версия</span>
      <span class="what"><strong>Нормализованный Telegram-текст.</strong> Специальная очищенная от ссылок и лишнего форматирования версия для публикации в чужих агрегаторах (чтобы избежать бана).</span>
    </li>
    <li>
      <span class="when">4 версии</span>
      <span class="what"><strong>Для внешних площадок.</strong> Тексты на немецком, английском, черногорском и русском для заливки на локальные доски объявлений.</span>
    </li>
  </ul>

  <h3 class="section-h3">Всё сохраняется само</h3>

  <p>Самое главное — администратору не нужно копипастить эти 13 текстов из Телеграма в базу. Бот полностью интегрирован по API с Headless CMS (Directus). Сгенерированные тексты автоматически "раскладываются" по правильным языковым и форматным полям в карточке объекта, подготавливая его к моментальной выгрузке автопостером (из <a href="#">третьего кейса</a>).</p>

  <blockquote class="pull">
    Агент просто диктует аудио с объекта, а система выдаёт полностью упакованный продукт на 6 языках, готовый к публикации везде.
  </blockquote>
</section>
